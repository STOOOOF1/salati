# صلاتي

تطبيق أندرويد بسيط لمواقيت الصلاة، فيه:

- الساعة الحالية والتاريخ الميلادي والهجري (أم القرى).
- الوقت الباقي على أذان الصلاة التالية.
- الوقت الذي مضى منذ أذان الصلاة السابقة.
- العدّ التنازلي للإقامة.
- الوقت الباقي على خروج وقت الصلاة الحالية، ويتحوّل لونه تدريجيًا إلى الأحمر كلما اقترب خروج الوقت (يبدأ قبل 30 دقيقة افتراضيًا).
- ثلاث ويدجتات للشاشة الرئيسية: صغيرة (2×2)، ومتوسطة (4×2)، وكبيرة (4×4) فيها جدول اليوم، وكلها قابلة لتغيير المقاس.

## الحساب

- طريقة أم القرى: الفجر 18.5°، والعشاء بعد المغرب بـ90 دقيقة (و120 في رمضان)، والعصر بظل المثل.
- نهاية الأوقات: الفجر حتى الشروق، والظهر حتى العصر، والعصر حتى المغرب، والمغرب حتى العشاء، والعشاء حتى منتصف الليل.
- الإقامة الافتراضية: الفجر 25، والظهر 20، والعصر 20، والمغرب 10، والعشاء 20 دقيقة، وتعديلها من الإعدادات.
- الموقع الافتراضي: المدينة المنورة، ويمكن اختيار مدينة أخرى أو الموقع الحالي.

## البناء

يُبنى ملف `salati.apk` تلقائيًا عبر GitHub Actions عند كل دفع إلى الفرع `main`، ويُنشر في قسم Releases باسم «latest».
محليًا: `./gradlew assembleDebug` (يتطلب Android SDK).
